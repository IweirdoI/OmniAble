# 对外文字与语音表达审核

状态：TASK-045 的本地文字模拟。TASK-028 的离线播报尚未接入；本样例只验证“原始意图 → 可审核
草稿 → 本人确认 → 模拟外发”的状态和安全边界。

## 样例

在「订单核验练习」的待核验订单详情中，对外表达面板显示：

- 原始意图：`告诉客户：蓝色收纳盒 3 件，单价 28 元，合计 84 元，周五前发货。`
- 待发送草稿：带相同价格与发货承诺的客户回复
- 草稿版本 `v1`
- 价格和发货承诺的确认勾选框
- 操作：确认草稿、模拟外发、取消、停止播报

## 状态规则

1. 原始意图与草稿始终同时可见。
2. 必须勾选“我确认价格与发货承诺，并允许发送当前版本”。
3. 修改草稿会递增版本并取消旧确认；旧版本不能直接外发。
4. 只有当前草稿版本被本人确认后，“模拟外发”才可用。
5. 取消后不播报、不外发。
6. “停止播报”只设置本地状态；本样例没有真实语音。
7. 同一确认版本重复外发会被阻止；结果面板只保留一条本地模拟结果。
8. 全程没有网络请求、真实外发、语音设备或音频。

## 语音与真实外发边界

- 当前标记“语音不可用 · 文字流程”；没有 TTS、没有播报、没有麦克风。
- 真实播报需 TASK-028 接入；真实外发渠道需要单独授权和验收，不能把本样例的本地提示当成
  已发送。
- 真实外发和模拟结果必须分开留证；本 PR 只记录模拟结果。
