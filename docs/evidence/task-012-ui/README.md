# TASK-012 工作台 UI 改版验收记录

日期：2026-11-23

分支：`codex/task-012-workbench`
对应：Issue #11 / PR #28；设计依据 `frontend/UI_DESIGN.md`（TASK-011，已验收）

## 改版范围

- 产品界面统一为 **OmniAble**：左上角使用本地 SVG 字标与“O + A”标志，页面标题、favicon、助理名称、欢迎语、空状态和无障碍名称同步更新。
- 桌面工作台拆成会话栏、聊天主区、辅助面板三块；辅助面板包含工作区、记忆、插件三个页签，可收起、切换和扩宽。
- 聊天、总览、接入、偏好、记忆、遗忘、文件与网页统一为深色中性面板与蓝色交互强调色，减少重复卡片和旧演示装饰。
- 手机顶部改为产品名、连接状态、菜单；菜单内完成用户切换、同步、插件、接入、遗忘、工作区和返回聊天。
- 同一用户导航保留草稿；切换用户清空草稿、聊天、遗忘输入、召回、同步状态和旧工作区组件状态。
- 记忆页签、辅助面板页签支持方向键与选中语义；菜单有可见关闭按钮、Escape、焦点循环和焦点返回。
- 面板保留逐项同步状态、最后成功时间、旧数据提示和单项重试。遗忘成功后先清除旧快照，再按实际刷新结果显示状态。
- 输入框使用持续存在的高度变量适配手机可视视口；键盘弹出/可视区域缩小时消息区收缩，输入框和发送按钮留在可视区域。
- 长文本换行；代码块、差异、文件内容只在自身区域滚动。增加 `prefers-reduced-motion` 处理。

## 本地插件工作台

本轮新增的是**前端本地插件宿主**，不是远程插件市场：

- 左栏“扩展”区域显示已启用插件，并可直接打开。
- 辅助面板新增“插件”页签：搜索、全部/已安装/可用筛选、安装、移除、打开、插件详情和返回列表。
- 随应用构建的三个实际插件：
  - **快捷指令**：选择模板后插入输入框，不自动发送；移动端插入后回到聊天并聚焦输入框。
  - **对话导出**：把当前临时会话下载为 Markdown，不经过后端。
  - **会话概览**：统计当前对话轮次、文本量和本轮召回数量。
- 启用状态保存在浏览器 `localStorage`；插件面板明确注明远程安装、权限审批和后端插件接口尚未接入。
- 插件只接受随应用构建的模块，不执行远程代码，不访问新增后端接口。

## 未验证 / 已知边界

- **没有在真实手机上验证系统软键盘**。当前用 390 × 360 可视视口和 `visualViewport` 高度变化模拟键盘占用；真实 iOS/Android 键盘的滚动与安全区仍需真机验收。
- **200% 缩放是等效视口测试**，通过 720 × 450 CSS 视口检查重排；没有在浏览器 UI 中实际拖动缩放级别。390 宽度的 200% 缩放不构成常规重排场景。
- **插件远程安装、权限审批、签名校验和后端插件接口未实现**。当前只有随应用构建的本地插件注册表和本机启用状态，不能据此宣称完整的第三方插件系统。
- 未运行真实模型 E2E、BGE-M3 语义效果、麒麟原生 SDK 或麒麟性能验收；本次只覆盖内存/hash 隔离 fixture 和前端交互。
- 未声称 CI 已通过；以上均为本机结果。
- `frontend/tests/ingestion-browser.cjs` 本轮尝试运行，在空白图片无说明的路径被**既有后端错误**阻断：`src/ingestion/staging_store.py` 的 semantic redact 分支在 `record=None` 时访问 `record.content`，返回 500。前端按设计显示了请求异常；该问题不属于本次 UI 改动，未在 TASK-012 中修改后端，也未改测试来掩盖。接入页的结构、标签、文件队列和用户切换仍由本目录的工作台回归和纯 Node 测试覆盖。
- 文件/网页工作区在 fixture 中未启用 `AGENT_ENABLE_WORKSPACE`，因此截图展示的是“连接你的工作目录”空状态；原有文件/变更/网页代码与测试保留，未新增接口。
