# OmniAble 产品方向与演示验收

OmniAble 是面向残障人士的通用无障碍 Agent 助手，目标覆盖用手机或电脑处理的生活、学习和工作任务。用户用适合自己的方式交代目标，再决定自己负责哪部分、交给 Agent 哪部分。能访问的应用和动作由设备能力、应用接入及当次授权决定。

## 使用流程

1. **直接交代要做的事**。可以输入文字、使用已接入的辅助输入，也可以选择文件或任务样例。适配配置可在使用中调整。
2. **选择协助程度**。用户可以自己操作、让 Agent 解释和提示；也可以和 Agent 分步协作，或授权 Agent 代办某个步骤或一组明确的操作。
3. **按需要参与和接管**。Agent 在信息不足、结果异常或即将产生外部影响时停下来，把依据、草稿和可选操作交给用户。用户可以补充、修正、拒绝、暂停或接管。
4. **核对结果**。能查看真实完成的步骤、来源、待处理事项和失败原因。外发、提交、支付、删除及产生实际后果的设备动作，要清楚展示对象和影响后再由用户确认。

生活任务可以从通知里提取日期并准备日程草稿。学习任务可以整理材料、给出来源并生成可修改的笔记。工作任务可以核对字段、填写重复表单或在授权后完成受支持的软件操作。固定岗位可以选择模板、练习资料和设备分工。用户也能直接从一件临时要做的事开始。

## 五条可组合的适配路线

以下路线提供适配示例。用户可以按操作困难组合输入、反馈和设备。同一种需求可以在生活、学习和工作中复用。[JAN 工作适配指南](https://askjan.org/disabilities/)

### 上肢操作受限 · 减少重复动作

适合探索商品定制、订单处理、样品展示和轻小物品备货。工作人员通过语音、替代鼠标或开关等可用输入表达目标和处理例外，Agent 填写订单、拆解任务并生成清单，机械臂执行获准的轻小物品取放。这条路线最适合把机械臂作为核心设备。示例中，工作人员确认客户方案并对缺货作出决定，Agent 更新清单后才继续备货。[JAN 动作能力适配](https://askjan.org/limitations/MOTOR.cfm)

### 下肢行动受限或到场困难 · 远程参与现场工作

适合探索远程接待、展品讲解、商品展示和现场运营支持。工作人员远程沟通和作业务判断，可继续使用熟悉的电脑输入。Agent 查询规格并记录询价，现场设备提供观察和展示能力。示例中，工作人员根据咨询请求切换展示商品，机械臂按需辅助转动展品或移动样品。[JAN 动作能力适配](https://askjan.org/limitations/MOTOR.cfm)

### 视障 · 独立获取信息并核验结果

适合探索文档处理、业务资料核验、客户服务和订单管理。工作人员通过键盘、读屏或语音获取内容，Agent 辅助提取和说明，工作台提供字段、来源位置、修改前后值和提交状态。示例中，工作人员能逐项核对商品、数量和金额，回查原始证据后决定是否提交。机械臂可按工作需要辅助固定或移动材料。[JAN 视障工作适配](https://askjan.org/disabilities/Blind.cfm)

### 听障 · 用文字参与沟通与接收提醒

适合探索前台服务、会议协作、技术支持及需要接收口头指令的岗位。工作台将语音转换成文字、标示发言者，并提供视觉或振动提醒。Agent 把口头请求整理成待确认事项。示例中，工作人员阅读客户的修改要求，纠正字幕里的规格，再让 Agent 改订单。[JAN 听障工作适配](https://askjan.org/disabilities/Deafness.cfm)

### 言语障碍 · 自主选择对外表达方式

适合探索咨询接待、商品讲解和远程支持。工作人员用文字或其他适合自己的方式表达，Agent 辅助组织内容，工作人员审核后选择语音播报或发送文字。示例中，工作人员编辑专业解释后播报，客户追问回到同一任务。价格、承诺和业务判断由本人确认。[JAN 言语障碍工作适配](https://askjan.org/disabilities/Speech-Language-Impairment.cfm)

## 三个参赛 Demo

### 动作辅助 · 定制订单与备货

工作人员确认定制方案，Agent 生成订单和物料清单，工作人员确认后由机械臂备货。故意安排一次缺货，验证人能暂停、选择替代方案并继续。记录手动点击或抓取次数、任务完成情况及人员接管是否有效。模拟取放和真机演示分别记录。

### 信息辅助 · 核验订单资料

使用键盘和读屏独立打开资料、定位字段、发现一处错误、核对修改并提交。记录键盘可达性、能否定位原始证据、发现错误与最终提交结果。验收由任务内实际操作记录支持。

当前可在「项目资料」打开订单核验练习，比较虚构的客户确认单与待核验订单，并从知识卡回查来源版本。完整的字段编辑、差异核验和提交仍在计划中。

### 沟通辅助 · 客户服务

听障路线演示读字幕、修正一次识别错误、确认客户需求并更新记录。言语障碍路线演示编辑回复、审核后播报或发送文字。记录沟通任务完成率、纠正后的业务字段是否正确，以及业务修改与外发是否得到本人确认。

## 共用基础与验证边界

已有工作台提供项目资料、来源版本、知识卡和分享包，也提供对话、文件工具、偏好与短中长期记忆。项目资料可用于任意个人或团队任务。通用任务委托计划接入现有工作台，复用会话、动作确认和运行记录。

手机端首先验证在移动浏览器中能发起任务、跟踪进展、确认或接管。手机其他 App 和电脑软件的操作能力按各平台实际接口或可用连接器逐项接入。端到端读屏、字幕和设备联动按实际环境验证。AgentArts 作为竞赛接入路径，按真实部署结果记录。[AgentArts 适配方案](designs/DOC-001-agentarts-adaptation.md) · [数据保留边界](DATA_RETENTION.md)

通用版首轮验收使用两条任务。一条从虚构生活通知整理日程草稿，一条从虚构工作资料核对字段。两条使用同一委托和接管机制，分别在电脑和手机端走通重要操作。[通用任务委托与无障碍协作设计](designs/DOC-002-accessible-job-workflow.md) · [Clerk 台账](TEAM_STATUS.md)
