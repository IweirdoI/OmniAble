# 发布说明

本仓库以 Windows 桌面应用为目标，提供本地 API、前端聊天和记忆工作区。日常开发使用 memory + hash，完整环境可使用 BGE-M3，持久化可连接 Milvus。

| 项 | 内容 |
|---|---|
| 公开来源快照 | <https://github.com/IweirdoI/mokoa-kylin> |
| 原版快照 | <https://github.com/IweirdoI/mokoa-kylin>，基线 `220bdd1` |
| 许可证 | 随上游保留 Apache License 2.0（见根目录 `LICENSE`） |
| 本人分工 | 偏好记忆 `src/preference/`。模块产出 `MemoryEntry`，不写 Milvus，不直接调用 `create_memory`。 |
| 方案正文 | [Linnea-偏好记忆整体技术方案.md](../Linnea-偏好记忆整体技术方案.md) |
| 相对原版增加 | `requirements-windows.txt`、`pyproject.toml`、`scripts/setup_windows.ps1`、`scripts/dev_windows.ps1`、`scripts/windows_env.ps1`、`docs/WINDOWS.md`、CI 作业 `test-windows`。特征覆盖脚本改用 `platform.platform()`。语料测试在缺少 pyarrow 时跳过。 |

按实际 Windows 机器、模型和后端记录新的验收结果。旧平台的报告保留其原始证据和归属。其余模块保留原项目贡献来源，以根目录 `README.md` 中的模块角色说明协作边界，不公开旧成员账户。
