# OmniAble 发布说明与贡献来源

本仓库为 OmniAble 的开发主仓。项目面向残障人士的岗位适配，围绕工作人员、Agent 和辅助设备协作设计。对外介绍见 [README](../README.md)，岗位路线和验收计划见 [产品说明](PRODUCT.md)。当前交付的技术基础是本地 API、项目资料、文件工作区、Agent 对话与记忆。Windows 日常开发使用 memory + hash，完整环境可使用 BGE-M3 和 Milvus。

| 项 | 内容 |
|---|---|
| 记忆系统的来源快照 | [上游项目](https://github.com/IweirdoI/mokoa-kylin/tree/220bdd1)，基线 `220bdd1` |
| 许可证 | 随上游保留 Apache License 2.0（见根目录 `LICENSE`） |
| 偏好记忆贡献 | Linnea 参与 `src/preference/`，模块通过 `MemoryEntry` 交接，入库走记忆编排。 |
| 方案正文 | [Linnea-偏好记忆整体技术方案.md](../Linnea-偏好记忆整体技术方案.md) |
| 相对原版增加 | `requirements-windows.txt`、`pyproject.toml`、`scripts/setup_windows.ps1`、`scripts/dev_windows.ps1`、`scripts/windows_env.ps1`、`docs/WINDOWS.md`、CI 作业 `test-windows`。特征覆盖脚本改用 `platform.platform()`。语料测试在缺少 pyarrow 时跳过。 |

按实际机器、模型、存储后端和辅助设备记录后续验证。以 [Agent 开工指南](AGENT_ONBOARDING.md#3-项目与模块索引)为模块入口，[贡献记录](../CONTRIBUTORS.md)为署名依据。历史评测保留原环境、证据与归属。
