# Windows 桌面 Agent 扩展路线图

目标是在断网的 Windows 桌面上，也能用语音或辅助输入完成一件具体的事。例如，用户示范填写一张表，指出每行会变化的字段，检查预览，再让应用录入下一批。本文是任务设计，实际认领、实现及验收以 [Clerk 状态页](TEAM_STATUS.md) 及其关联 Issue 为准。

## 当前主线与需要改的地方

- [聊天服务](../src/agent/service.py) 中的 `_LOCAL_TOOL_NAMES`、`_run_local_tool` 和模型工具分派认识具体工具。[工作区 API](../api/workspace.py) 另有面向界面的入口。继续给每个入口加一套工具会使语音和定时任务很难复用文件版本检查、权限和错误处理。先从计算与只读文件两个动作接通共用目录，再迁移写操作。
- [RunContext](../src/agent/runtime.py) 已处理一次请求内的取消、超时和流式连接。[工作流约定](AGENT_WORKFLOW.md) 已定义预算和终态。批量录入需要知道“第几行已提交”，定时任务需要知道“哪个时点已触发”。为它们增加可持久化的执行记录，沿用已有状态含义，保留普通聊天断线取消的行为。
- [工作区](AGENT_WORKSPACE.md) 以配置的文件根目录限制访问，前端传入的用户 ID 不提供文件鉴权。新增桌面宿主需绑定本地身份、会话和明确授权的工作区。批准某个插件、保存某个模板、批准这一次写入是三件不同的事。
- [记忆编排](../src/core/orchestrator.py) 继续负责长期知识、偏好与遗忘。[上下文预算](../src/agent/context.py) 与[出站脱敏](OUTBOUND_PRIVACY.md) 继续作用于送给模型的内容。录入的数据、执行到第几行、代码依赖图各有独立用途和删除期限。复用模板无需先把操作过程录成长期记忆。

## 一次动作如何执行

1. 按钮、语音、模型、录制回放或时钟提交动作 ID、版本和参数；宿主绑定执行者、触发来源与工作区。语音识别出“提交”只表达意图。
2. 宿主查动作是否可用、是否允许当前来源执行，以及是否要当场确认。预览明确列出目标、范围和副作用。一次性批准绑定到目标、参数、版本和时限，重放模板或历史对话不能继承上次批准。
3. 内置适配器或受限插件执行；宿主负责取消、预算、结果核验。表单提交已发出但取不到回执时，行状态为“待核对”；恢复后由用户核对再继续。对没有幂等接口的外部软件，不能依靠重试推断成功。
4. 用同一份结果驱动桌面显示、读屏播报和运行记录。用户可以不听播报、也可以不用鼠标查看进度和停止执行。模型按需取得经授权的短摘要；默认不接收表格行、原始音频或整库源码。

## 认领顺序

编号按登记顺序，开发顺序按依赖。首次对接用合成数据。每个 Issue 列出了建议修改范围、前置任务及能复核的验收场景。

- **可以并行开工**。TASK-021 做统一动作入口与本地调用身份；TASK-023 做离线插件包与验签；TASK-025 做断网配置和模型缺失时的能力清单；TASK-034 明确数据保留和遗忘范围。TASK-035 的测试场景与无障碍使用者反馈方式也可以先设计。插件包、签名和离线验签契约见 [PLUGIN_PACKAGE.md](PLUGIN_PACKAGE.md)。
- **第一个用户闭环是录一遍、填多行**。TASK-027 让命令可由键盘、读屏和语音定位；TASK-029 在工作台内录一张合成表单，参数化变化字段。TASK-022 提供运行恢复，TASK-030 将模板用于一批数据。TASK-028 接入离线普通话与可打断播报；TASK-036 将同一流程扩展到用户指定的 Windows 原生窗口。
- **分发与后台运行**。TASK-024 用内置工具验证插件宿主，再由 TASK-026 打成可校验、可回滚的 U 盘发行包。程序由用户在允许使用介质的终端显式启动；现场策略阻止执行时给出明确原因。TASK-031 首版在宿主运行期间调度，退出、睡眠和拔盘期间错过的任务在下次启动可见。真正关机期间的执行或企业后台服务需要另行确定运行环境。
- **用代码解析检验插件边界**。TASK-032 先用 Python 样例校验静态依赖图；TASK-033 让用户从 AI 解释中的判断跳到依赖边和对应版本源码，无模型时仍可查图。TASK-037 后续用一个只读本地 MCP 服务验证第三方工具接入。
- **目标环境验收**。TASK-035 汇集干净 Windows 机器、无公网、无管理员权限、辅助技术与真实使用反馈。单元测试覆盖逻辑，真机实际走过的操作、已知障碍和用户反馈分别留证。可分组交付并分别验收，首个办公闭环可先于代码插件交付。

## 与已有工作的接口

- TASK-012 已有工作台设计与键盘/焦点要求；TASK-027 扩展稳定命令和辅助输入。TASK-015 提供前端回归入口，TASK-035 补真机与使用场景。
- TASK-018 负责会话恢复，TASK-022 负责动作运行恢复；两者可按用户和会话引用关联。TASK-020 的逐次文件写入确认继续有效，批量表单授权不授予文件写入权限。TASK-019 已有的上下文预算也约束新插件工具描述、代码解释和结果摘要。
- TASK-007 验收 Windows 目标后端的检索性能；TASK-026 和 TASK-035 另外记录离线包体积、硬件、可用模型与辅助技术。两类结果各自按实际环境登记。
