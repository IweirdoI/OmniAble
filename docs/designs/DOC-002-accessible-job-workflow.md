## 适用范围与状态

本设计覆盖岗位选择、适配配置和练习任务的最小契约，供 [TASK-042 / Issue #62](https://github.com/IweirdoI/OmniAble/issues/62) 及各 Demo 的实现者共同评审。当前是设计草案，仓库已有本地项目资料和独立的订单核验练习样例。各任务状态见 [Clerk 台账](../TEAM_STATUS.md)。

## 产品缺口

- 已有 Vue 项目资料、来源版本与知识卡，可作为岗位资料入口。Agent 已有会话、工具确认、动作目录、运行状态与中断记录，可用于对应的执行层。
- 缺少岗位模板及辅助方式配置。当前聊天场景能传递上下文，尚无岗位内可复用的练习状态和带来源的字段。
- 五条适配路线仍缺端到端工作流。当前语音能力清单是占位，需要用 TASK-028 接线。设备控制、上线部署和项目成员权限各自需要验收。

## 工作台流程

项目资料保持首页。从岗位入口选一项工作，再按需要配置输入、反馈和辅助设备。允许跳过适配选择，允许跨方向组合，配置只保存本人选择的能力。岗位模板提供资料、任务步骤、必填字段、需要确认的行为以及可选设备。可用输入和设备应根据运行环境反馈；缺少设备时显示可行替代路径。

先运行虚构练习，进入正式工作时重新确认当前输入、环境与执行授权。界面明确标示运行模式。练习输出进入单独的本地记录，不能触发真实订单提交、外发或实体动作。重新加载后恢复草稿或等待状态，由工作人员决定如何继续；已执行和执行结果未知的步骤不得被自动重发。

## 共享契约草案

- **岗位模板**记录稳定标识、修订版本、步骤、所需与可选能力、资料入口及确认点。首轮只需支持订单核验和一条可替换的第二岗位样例。
- **练习任务**记录岗位版本、模式、用户选择、当前步骤和草稿。任务层引用 Agent 会话或运行记录，只保存本领域的状态。设备不可用、暂停、待确认、成功与失败均有文字状态。
- **证据引用**携带资料标识、版本和字段定位。提交前显示原值和新值。来源更新或草稿被修改后重新确认。可能无法定位的提取结果显示待查。
- **执行确认**绑定当前任务、草稿内容、行动类型及当前版本。外发和设备操作只接收明确获准的动作。重复提交返回同一结果，断联或超时转为可核对状态，避免自动重发。
- **记录与隐私**复用 [数据保留边界](../DATA_RETENTION.md)。练习、本人适配选择、原始音频和执行授权各有明确用途；向外部服务发送所需的最小数据，用户能在界面了解数据去向及保留方式。团队共享权限另行设计。

## 实施步骤

1. P0 由 [#62](https://github.com/IweirdoI/OmniAble/issues/62) 交岗位入口、配置和草稿恢复，[#63](https://github.com/IweirdoI/OmniAble/issues/63) 并行做可读屏的来源与差异核验。以同一份虚构订单演示从进入岗位到提交演示记录。先评审两者共享的数据字段。
2. P1 由 [#64](https://github.com/IweirdoI/OmniAble/issues/64) 和 [#65](https://github.com/IweirdoI/OmniAble/issues/65) 分别交付字幕纠错和对外回复确认。用可重放输入和文字降级先跑通流程，接入现有 TASK-028 的语音能力后再做语音验证。
3. P1 由 [#66](https://github.com/IweirdoI/OmniAble/issues/66) 先做备货模拟、失败状态与人员接管，核对现有 TASK-021 动作目录、TASK-022 运行记录的复用，再定真机接口。[#68](https://github.com/IweirdoI/OmniAble/issues/68) 基于 [AgentArts 适配方案](DOC-001-agentarts-adaptation.md) 做云端接入，部署探针可先做，业务验收跟随 #63。
4. P2 的 [#67](https://github.com/IweirdoI/OmniAble/issues/67) 和 [#69](https://github.com/IweirdoI/OmniAble/issues/69) 分别设计远程接待、共享权限与撤销访问。远程设备状态复用 #66 的契约，团队权限验收保留现有本地分享包兼容性。

## 验收与交付

浏览器测键盘可达、可见焦点、文字状态、取消和来源变更；语音与读屏的验证使用实际辅助技术和目标环境。首次人工验收走完整的订单核验，再分别验证字幕纠错接业务、模拟缺货后恢复。已有 TASK-027 提供桌面辅助命令，TASK-035 汇总真实设备与辅助技术验收。外部模型、AgentArts 云部署以及机械臂真机均分别记录。

## 待确认事项

首轮评审确认任务与 Agent 运行的关联字段、草稿保存位置、来源变化后的提示策略、工作与练习的权限切换，以及各岗位可支持的输入和设备。实现者先走可复现的虚构任务，邀请使用辅助技术的人员复核时记录环境与反馈并保护隐私。
