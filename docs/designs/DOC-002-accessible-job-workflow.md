## 适用范围与状态

本设计覆盖通用任务入口、无障碍交互、Agent 执行授权和用户接管，供 [TASK-042 / Issue #62](https://github.com/IweirdoI/OmniAble/issues/62) 及各场景实现者共同评审。当前是设计草案。首轮用生活通知和工作资料两类任务验证共用流程。各任务状态见 [Clerk 台账](../TEAM_STATUS.md)。

## 产品缺口

- 已有 Vue 对话、项目资料、来源版本与知识卡。Agent 已有会话、工具确认、动作目录、运行状态与中断记录，可以支持任务的执行层。
- 缺少面向用户的通用任务状态，以及协助、分步协作、授权代办与接管之间的交接。手机响应式布局已有基础，手机上的任务确认、辅助技术验证及应用连接器需要独立交付。
- 语音能力需与 TASK-028 接线。真实设备控制、云部署和团队成员权限分别验证。

## 工作台流程

从任务入口直接输入目标，可附上用户选择的文件、网页或工作资料。输入和反馈配置可以在使用中调整，保存本人选择的能力。任务模板是快速入口，可覆盖日程、学习资料、常用工作流程等。设备和工具按当前环境显示可用范围，并为不可用的步骤提供文字说明或手动完成路径。

Agent 返回下一步计划，用户可以亲自操作、分步协作或授权 Agent 执行支持的操作。Agent 遇到缺失信息、异常或外部影响时暂停并交回决定。用户能查看实际完成和待处理的步骤，并中途接管。虚构练习输出进入独立记录。重新加载后恢复草稿或等待状态，已执行和结果未知的步骤不得自动重发。

## 共享契约草案

- **任务请求**记录用户目标、选定来源、协助程度与可执行范围。模板可附带建议步骤和确认点，临时任务可以直接提交。数据字段和状态名在实现前评审。
- **任务进度**记录模式、当前步骤和草稿，引用 Agent 会话或运行记录。暂停、等待用户、可接管、成功、失败和结果未知用可读文字反馈。等待用户确认期间不启动被拦截的动作。
- **证据引用**携带资料标识、版本和字段定位。提交前显示原值和新值。来源更新或草稿被修改后重新确认。可能无法定位的提取结果显示待查。
- **执行确认**绑定任务、行动、目标、草稿内容及当前版本。用户可授权一组明确的低影响操作。外发、正式提交、支付、删除、实体设备动作等有外部后果的操作需展示影响后单独确认。重复提交返回同一结果，断联或超时转为可核对状态，避免自动重发。
- **记录与隐私**复用 [数据保留边界](../DATA_RETENTION.md)。练习、本人适配选择、原始音频和执行授权各有明确用途；向外部服务发送所需的最小数据，用户能在界面了解数据去向及保留方式。团队共享权限另行设计。

## 实施步骤

1. P0 由 [#62](https://github.com/IweirdoI/OmniAble/issues/62) 交通用任务入口、协助和代办状态、暂停接管与结果回执。[#70](https://github.com/IweirdoI/OmniAble/issues/70) 并行设计手机端，复用同一状态和确认机制。[#63](https://github.com/IweirdoI/OmniAble/issues/63) 验证来源与差异核验，作为工作样例。
2. P1 由 [#64](https://github.com/IweirdoI/OmniAble/issues/64) 和 [#65](https://github.com/IweirdoI/OmniAble/issues/65) 分别交付字幕纠错和对外回复确认。用可重放输入和文字降级先跑通流程，接入现有 TASK-028 的语音能力后再做语音验证。
3. P1 由 [#66](https://github.com/IweirdoI/OmniAble/issues/66) 先做备货模拟、失败状态与人员接管，核对现有 TASK-021 动作目录、TASK-022 运行记录的复用，再定真机接口。[#68](https://github.com/IweirdoI/OmniAble/issues/68) 基于 [AgentArts 适配方案](DOC-001-agentarts-adaptation.md) 做云端接入，部署探针可先做，业务验收跟随 #63。
4. P2 的 [#67](https://github.com/IweirdoI/OmniAble/issues/67) 和 [#69](https://github.com/IweirdoI/OmniAble/issues/69) 分别设计远程接待、共享权限与撤销访问。远程设备状态复用 #66 的契约，团队权限验收保留现有本地分享包兼容性。

## 验收与交付

首轮在电脑和手机浏览器分别走虚构生活通知及工作资料任务。验证用户可直接发起、授权低影响步骤、暂停、拒绝外发、接管及核对结果；一次中断后恢复到正确状态。浏览器测键盘、文字状态和取消，真实读屏及语音按实际辅助技术验收。已有 TASK-027 提供桌面辅助命令，TASK-035 汇总真机验收。AgentArts 和机械臂按各自实施状态记录。

## 待确认事项

首轮评审确认任务与 Agent 运行的关联字段、草稿保存位置、权限与接管交界、跨端会话条件和端侧工具支持范围。安排使用辅助技术的用户参与时，记录可公开的操作环境与反馈并保护个人数据。
