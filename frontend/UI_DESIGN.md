# 聊天与记忆工作台界面方案

关联：#10 / TASK-011；实现：#11 / TASK-012。状态：待维护者审查。

## 目标与原则

以聊天为主工作区，文件、网页、记忆作为可打开的辅助面板。参考 DeepSeek Harness 的工作区组织方式，以清晰的导航和宽敞的内容区承载后续扩展；本方案不声称实现插件系统。沿用 Vue 和现有 API、数据权限与演示模式，保留全部现有 data-testid。

## 页面结构

桌面（1440×900）：

```text
┌─ MOKOA ─────────────────────────────────── 用户 / 同步 / 连接状态 ─┐
│ 会话             │ 对话                          │ 工作区 / 记忆  │
│ 新对话           │ 消息与执行状态                │ 文件 / 网页    │
│                  │                               │ 总览 接入 偏好 │
│                  │                               │ 记忆 遗忘      │
│                  │                               │ 内容与状态     │
│                  │ 输入框                        │                │
│                  │ 接入 · 使用记忆 · 保存 · 发送  │                │
└──────────────────┴───────────────────────────────┴────────────────┘
```

聊天占主要宽度；辅助面板可收起、打开和扩宽，文件与网页沿用现有功能。窄桌面或 200% 缩放时，辅助面板以独立区域呈现，不能遮住输入或造成整页横向滚动。新对话只创建当前已有的临时会话，不暗示历史会话持久化。未来扩展入口应能容纳新面板，但不展示不可用的插件按钮。

手机（390×844，768px 同样检查）：顶部显示产品名、连接状态和菜单；菜单提供用户切换、同步及工作区/记忆入口。聊天与输入区优先占屏；打开辅助面板时切换至完整可滚动视图，并提供返回对话的按钮。键盘弹出时输入及发送保持可达。菜单和面板打开、关闭均有可见文字和辅助技术名称。

```text
┌─ MOKOA ─── 演示模式 ── 菜单 ─┐
│ 对话                         │
│                              │
│ 消息与执行状态               │
│                              │
│                              │
│ 输入消息                     │
│ 接入   记忆选项       发送 ↑ │
└──────────────────────────────┘
```

## 关键页面

- **聊天**：减少重复头像和装饰标题；用户消息与助手回答易于区分。流式内容、执行阶段、停止、失败与部分结果继续显示。新对话、接入、记忆使用和保存选项都可操作。
- **总览**：保留统计、分层和活动；数字及来源清晰，显示同步时间和失败状态。只显示服务实际返回的信息。
- **接入**：保留文件和文本入口、处理进度、结果及失败原因；窄屏纵向排列，标签始终可见。
- **偏好**：当前偏好和版本历史分区；长键可换行或局部滚动，值保持可读，遗忘入口有明确对象。
- **记忆**：本轮召回与长期记忆浏览明确区分。长期浏览依现有已合入 API 及任务边界衔接，显示真实数据与分页状态；不把本轮召回冒充全部记忆。
- **遗忘**：输入框有可见关联标签，说明操作范围；处理、成功、失败及返回数量以实际响应为准，结果用文字播报。
- **文件与网页**：沿用现有工作区功能，标签、预览、变更和操作在桌面与手机均可达。

## 视觉规范

深色中性背景：页面 `#101114`，面板 `#181a20`，边框 `#343943`，主文字 `#f1f3f7`，次级文字 `#b1b8c5`；交互强调蓝 `#8ab4f8`，危险操作 `#ef9a9a`。状态以文字和图标同时表达，颜色不是唯一提示。正文 16px、辅助文字不小于 14px、主要标题 20–24px；正文行高约 1.6。间距采用 4/8/12/16/24px，点击目标至少 44px；卡片只用于需要分组的内容，减少重复边框。

所有可交互控件有一致的默认、悬停、禁用和至少 2px 的可见焦点样式；焦点顺序跟随视觉顺序。标签使用真实关联，导航选中状态通过语义表达。图标配文字或无障碍名称。尊重系统减少动态效果设置。长中文可换行；代码块和表格仅在各自区域横向滚动。

## 状态与文案

| 状态 | 呈现 |
| --- | --- |
| 连接中 | 显示“正在连接”，相关操作按实际需要禁用 |
| 已连接 | 显示“已连接”，提供用户切换和同步 |
| 演示 | 始终显示“演示模式”，演示数据不标为真实结果 |
| 加载 | 对应区域显示“正在加载”，保留可操作的其他区域 |
| 空 | 解释当前没有内容及可用的下一步 |
| 失败 | 显示失败区域和原因，提供可用的重试；旧数据须标明未更新 |
| 部分完成 | 明确显示已完成和失败部分，不以成功状态代替 |

状态变化通过适当的状态或警告区域播报；不移动用户焦点打断输入。
